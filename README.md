# **Odd or Even**

### **Problem Statement:**

Write a program that takes 1 line of input:

- An integer.

The program should print `Even` if the integer is divisible by 2. Otherwise, print `Odd`.

---

### Sample Input 1:
4

### Sample Output 1:
Even

### Explanation:
4 is divisible by 2, so the program prints `Even`.

---

### Sample Input 2:
7

### Sample Output 2:
Odd

### Explanation:
7 is not divisible by 2, so the program prints `Odd`.

---

### Sample Input 3:
0

### Sample Output 3:
Even

### Explanation:
0 is divisible by 2, so the program prints `Even`.
